# 🧑‍💼 Human Resource Management System (HRMS) - Flask App

A web-based Human Resource Management System (HRMS) developed using **Flask** and **MySQL**, supporting admin and employee login functionality. This application serves as a foundational structure for managing employee records, timesheets, and internal HR operations.

---

## 🚀 Features

- **Admin Login**
  - Access to admin dashboard
  - View employee list
  - Approve timesheets
  - Access reports, settings, notifications, and helpdesk

- **Employee Login**
  - Access to employee dashboard
  - Submit timesheets
  - View personal attendance and settings

- **Authentication**
  - Secure login with session management
  - Role-based access control for admin and employees

- **Frontend**
  - Clean and responsive user interface using HTML, CSS

> ⚠️ *This version includes frontend and basic login functionality. Other backend modules like attendance reports, approval systems are currently UI-only (not database-linked).*

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap (optional)
- **Backend**: Python (Flask)
- **Database**: MySQL (via SQLAlchemy ORM)
- **Tools**: Flask, Jinja2, SQLAlchemy, PyMySQL
